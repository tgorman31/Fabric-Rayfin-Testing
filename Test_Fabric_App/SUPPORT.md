# Support

This repository is the support front door for the Fabric Rayfin Project Index application. It does not establish a permanent service desk, production owner, support hours or response targets.

## Start here

1. Read the [troubleshooting guide](docs/operations/troubleshooting.md).
2. Check the [configuration reference](docs/operations/configuration-reference.md) if the problem concerns local or Fabric configuration.
3. Use [support and escalation](docs/operations/support-and-escalation.md) to assemble evidence and identify the relevant function.
4. Review the [production-readiness register](docs/security/production-readiness-register.md) when the issue concerns an unconfirmed operational or security control.

The [documentation index](docs/index.md) links to the wider application, architecture and security guidance.

## Before raising an issue or support request

Record the symptom, exact user-visible error, date/time and timezone, environment, route, scope (one user or many; one project or many), reproduction steps, and the last known good behaviour if known. Review screenshots, logs and browser network/console output before sharing them.

## Do not include

Never paste any of the following into a GitHub issue, ticket or chat:

- passwords
- access tokens
- session tokens or cookies
- secret-bearing environment files
- unredacted sensitive logs or personal/project data

Use placeholders and describe the type of value instead.

## Production support ownership

A permanent production support owner is **not currently documented**. A production support ownership and escalation model must be agreed before organisational rollout. The role descriptions in [support and escalation](docs/operations/support-and-escalation.md) are proposed functions, not named teams or an existing operating model.
